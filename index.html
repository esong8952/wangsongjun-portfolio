售前实战：医疗信息化项目

社团数字化是我"自己找需求、自己交付"的端到端练手；而售前岗位的核心能力——需求诊断、方案编制、高层汇报、合规交付——我在医疗信息化一线项目里有真实的完整历练。以下三个案例来自实习与项目经历，数据与简历一致，可逐条核对。

01
熙牛医疗科技 · 售前全周期支持
准独角兽企业 · 2026.04 – 至今
痛点：医疗信息化项目售前周期长，从需求诊断到交付物编制再到技术宣讲全靠个人串联，效率低、易遗漏，难以规模化复制。
方案：参与售前全周期支持——客户现场需求诊断、交付物编制、多轮技术宣讲；独立完成 POC 演示脚本编写，经评审后面向客户交付，把技术能力转化为客户可感知的业务场景；快速掌握多条核心产品线，结合 AI 应用场景（智能问诊、病案质控等）做差异化方案讲解；跟踪国家卫健委 84 项 AI 应用场景与公立医院高质量发展政策，输出竞品差异化分析。
需求诊断POC 演示竞品分析差异化方案
业务价值：完成 2500+ 条工作量评估支撑项目预算编制，相关项目累计涉及资金额超 2 亿元；竞品差异化分析已有多项进入公司标准方案库，直接支撑业务拓展。

02
三甲医院电子病历五级评级方案
方案核心成员 · 2026.05 – 2026.06
痛点：医院冲刺电子病历系统功能应用水平五级评级，需在规定期限内完成差距分析并输出整体建设方案——评级标准条目多、逐条对位工作量大，纯人工对位易出错漏项。
方案：协助售前经理研读评级标准，逐条对标医院现状输出差距分析矩阵；引入 AI 辅助政策对标（大模型解析评级标准自动生成差距矩阵），独立完成方案 PPT 编制，经 5 轮迭代实现政策原文逐条对位；面向客户高层进行多轮方案试讲与正式汇报，输出 20min/30min 双版本。
政策对标差距分析方案编制高层汇报
业务价值：辅助销售推进项目立项，积累标杆客情；方案通过内部评审纳入公司标准方案库并在后续项目中复用；个人宣讲与客户沟通能力在"读稿→讲稿→脱稿"三阶段训练中显著提升。
▸ 关键数据：5 轮迭代 · 10+ 场高层汇报 · 20min/30min 双版本 · 入标准方案库
03
卫健局信息化项目 · 验收交付与等保合规
信息科助理 · 2025.07 – 2025.09

方案：协助信息化项目验收会议，编制验收材料并参与现场支持；协调安全厂商推进等保整改，在实战中积累政府侧项目审批流程与合规经验。
验收交付等保 2.0政府审批流程

Solutions

8 个可独立交付的解决方案

每个方案均按"业务痛点 → 解决方案 → 核心能力 → 业务价值"的售前逻辑组织，且都构建于上方"AI 中台"的共享能力层之上。

01
协会知识库智能问答系统
RAG 式顾问 · 核心作品
痛点：139 人跨校区协会，流程答疑、值班提醒等重复沟通占核心成员大量工时，知识靠口口相传。
方案：设计"知识沉淀→智能问答→数据运营"三层方案；飞书知识库（83 篇文档、分层组织）作底层，调用大模型 API 结合 LangChain/RAG 构建智能问答，覆盖流程答疑、新人引导、值班提醒等高频场景。选用飞书低代码而非自研平台——交付轻、落地快、运维薄、可平滑迁移至任意协同办公客户场景。
知识检索路由幻觉防护LangChain/RAG低代码取舍
业务价值：SOP 标准化率 90%+，新人培训效率提升 50%；方法论可复用于企业知识中台 / 智能客服。
▸ 关键数据：分层知识库 83 篇 · 覆盖 139 人 · SOP 标准化率 90%+
02
SOP 流程引导 Agent
多流程编排 · 带安全边界
痛点：企业对接 / 宣讲会 / 招聘会等标准动作没人带就走样，新人怕出错不敢干。
方案：7 类流程状态机，按阶段引导"在哪、该做什么、下一步"，检查点强制标注，对外沟通给现成话术模板；内置插件保护口令防 prompt 越权改规则。SOP 已迭代 3 版。
流程状态机检查点提醒话术生成安全边界
业务价值：流程标准化、降低执行出错率；3 版迭代体现需求→交付闭环。
▸ 关键数据：7 类流程 · SOP 迭代 3 版
03
文档自动化生成器
模板驱动 + 质量门
痛点：会议纪要 / 话术 / 推文 / 考核报告靠人写，质量参差、风格不一。
方案：模板驱动 + 黄金标准约束（一句话结论、>500字必拆清单、新人按文可独立操作）。
模板驱动约束式质量门
业务价值：提效且统一输出标准，降低对"会写的人"的依赖。
04
新人 Onboarding Agent
渐进式交互 / 体验设计
痛点：新人"怕做砸"焦虑，一次性灌输信息反而记不住。
方案：渐进式信息释放（先讲"最该知道的"）+ 共情语气（温暖学长学姐人设）。
渐进式交互共情体验设计
业务价值：降低新人焦虑、提升上手速度与留存。
05
活动策划 / 复盘助手
经验库复用
痛点：活动策划从零写、复盘经验不沉淀。
方案：模板 + 历史经验库（破冰 / 元旦晚会 / 职场挑战赛复盘）复用，策划控 1 页 A4、复盘分详细 / 快速两版。
经验库复用模板化产出
业务价值：策划提速、经验资产化。
▸ 关联真实战果：统筹 4 场职场体验行（200+ 问卷调研），推动 600+ 名学生进入企业场景
06
考试通过助手
多源融合 / 闭环校验
痛点：复习资料散（要点清单 doc + 教材 PDF + 题库 md），人工整合慢、易漏知识点。
方案：多源融合 → 自包含 HTML 复习指南（三重导航 + 答案折叠 + 题解必含）。技术链：markitdown 解析 → 缺口审查闭环 → 题库转 quiz → 质量校验。
多模态解析缺口检测闭环结构化编排
业务价值：零散资料一键变体系化指南，最能体现工程落地能力。
07
飞书值班仪表盘（低代码）
真实落地 · 含截图

低代码数据工程公式引擎踩坑
业务价值：排班透明化，核心团队排班数据实时可视。
